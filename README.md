# SalaryOS

SalaryOS is a native personal finance application for iOS and macOS, designed around Latvia. It is under active development.

## Current status

- Phase 0 repository and environment inspection: complete.
- Phase 1 app foundation: complete.
- Phase 2 financial domain and ledger: complete.
- Phase 3 account, transaction and dashboard workflows: complete.
- Phase 4 Latvian tax engine: next.

See [DEVELOPMENT.md](DEVELOPMENT.md) for toolchain and build commands, [ARCHITECTURE.md](ARCHITECTURE.md) for module boundaries, [DATABASE.md](DATABASE.md) for ledger and persistence invariants, and [ROADMAP.md](ROADMAP.md) for upcoming work. Salary calculation and tax rules are not implemented yet.
