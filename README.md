# SalaryOS

SalaryOS is a native personal finance application for iOS and macOS, designed around Latvia. It is under active development.

## Current status

- Phase 0 repository and environment inspection: complete.
- Phase 1 app foundation: complete; iOS and macOS targets build.
- Phase 2 financial domain: next.

See [DEVELOPMENT.md](DEVELOPMENT.md) for the toolchain and build commands and [ROADMAP.md](ROADMAP.md) for milestones. The app does not yet provide finance workflows or tax calculations.
