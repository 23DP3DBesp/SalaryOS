# SalaryOS

SalaryOS is a native personal finance application for iOS and macOS, designed around Latvia. It is under active development.

## Current status

- Phase 0 repository and environment inspection: complete.
- Phase 1 app foundation: complete.
- Phase 2 financial domain and ledger: complete.
- Phase 3 account, transaction and dashboard workflows: complete.
- Phase 4 Latvian tax engine: in progress (2026 monthly estimate and annual PIT estimator are available).

See [DEVELOPMENT.md](DEVELOPMENT.md) for toolchain and build commands, [ARCHITECTURE.md](ARCHITECTURE.md) for module boundaries, [DATABASE.md](DATABASE.md) for ledger and persistence invariants, and [ROADMAP.md](ROADMAP.md) for upcoming work. The current salary estimate covers standard Latvian employment under the 2026 rule set.


Salary estimates use the documented Latvia 2026 rule set. See [TAX_ENGINE.md](TAX_ENGINE.md) for sources, formulas, and limitations.
