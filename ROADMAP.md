# Roadmap

**Complete:** confirmed that the starting repository was empty and had no project settings, dependencies, entitlements, build targets, or tests. Recorded the installed toolchain and active Xcode selection limitation in [DEVELOPMENT.md](DEVELOPMENT.md).

## Phase 1 — Foundation

**Complete:** added shared SwiftUI source, iOS and macOS app targets, SwiftData container composition, adaptive initial navigation, native light/dark system appearance, Latvian/English/Russian string catalog, and a localized storage initialization error screen.
